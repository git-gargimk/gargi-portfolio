# Gargi Kulkarni — Portfolio

A responsive React portfolio with four hash-linked tabs, keyboard navigation, filterable projects, accessible project dialogs, and LinkedIn contact actions. Built with Vite and React.

## Develop

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

The production output is `dist/`. All portfolio content is in `src/main.jsx`; design tokens, responsive layouts, and illustrations are in `src/styles.css`.

Content is based on the publicly indexed LinkedIn profile at https://www.linkedin.com/in/gargimrunalkulkarni/. Employment titles and dates that were not available were omitted. The project illustrations are original visual interpretations, not product screenshots.
